## 目的

英语元音拼写是中国学生最难的部分——同一个发音可能对应多种拼写（e, ea, ee 等）。切块拼写将单词在元音/音节边界处切开，让学生主动重建，把最难的学习点变成可操作的游戏机制。4 级难度曲线对应布鲁姆认知分类（记住→理解→应用→创造），确保认知递进。本功能覆盖月份（12个）和星期（7个）共19个词汇。

## 用户故事

### US-1：元音识别（新手）

**作为** 初学者
**我想要** 把元音拖回单词中的空位
**以便** 我学会识别英语单词中的元音位置

**验收标准：**

- [ ] 单词显示时元音被挖空，空位有标记
- [ ] 元音选项显示在单词下方的选项池中
- [ ] 将元音拖到正确位置 → 吸附动画 + 积极音效
- [ ] 将元音拖到错误位置 → 弹回 + 震动 + 不扣分
- [ ] 所有元音填对 → 单词炸裂特效 + "Perfect Spelling!" 语音

### US-2：音节排序（普通）

**作为** 中级学生
**我想要** 把打乱的音节块拖回正确位置
**以便** 我学会音节如何组合成完整单词

**验收标准：**

- [ ] 单词显示时音节空位有位置标记
- [ ] 音节块在选项池中打乱显示
- [ ] 将块拖到正确位置 → 吸附 + 音效
- [ ] 拖到错误位置 → 弹回 + 震动
- [ ] 所有音节放对 → 单词炸裂 + "Perfect Spelling!"

### US-3：音节辨别（困难）

**作为** 高级学生
**我想要** 从含干扰项的选项池中选出正确的音节块
**以便** 我能区分相似发音的拼写

**验收标准：**

- [ ] 音节空位有位置标记
- [ ] 选项池包含正确块 + 干扰项（如 "tem" vs "tim"）
- [ ] 选到正确块 → 吸附到位置
- [ ] 选到错误块 → 弹回 + 震动
- [ ] 所有正确块放对 → 单词炸裂 + "Perfect Spelling!"

### US-4：自由构建单词（大师）

**作为** 专家级学生
**我想要** 在没有位置提示的情况下从音节碎片组装出完整单词
**以便** 我展示对单词构建的完全掌握

**验收标准：**

- [ ] 无位置标记 — 只有空白组装区
- [ ] 选项池包含正确块 + 干扰项
- [ ] 玩家自由组合块构建完整单词（不要求从左到右顺序放置，放入错误位置则弹回）
- [ ] 错误块 → 弹回 + 震动
- [ ] 构建出正确完整单词 → 炸裂 + "Perfect Spelling!"

## 功能需求

### FR-1：单词数据模型

每个单词必须包含：
- `word`：英文拼写（如 "September"）
- `phonetic`：国际音标（如 "/sɛpˈtɛmbər/"）
- `meaning`：中文释义（如 "九月"）
- `vowelChunks`：元音位置和值的数组（如 `[{index:1, value:"e"}, {index:3, value:"e"}, {index:5, value:"e"}]`）。index 为切分后段落的序号（如 September 切分为 S(0)|e(1)|pt(2)|e(3)|mb(4)|e(5)|r(6)，奇数段为元音段，偶数段为辅音段）
- `syllableChunks`：音节段数组（如 `["Sep", "tem", "ber"]`）
- `difficulty`：难度浮点值 0-1
- `distractors`：困难/大师模式用的相似音节干扰项池（如 `["tim", "bor", "sep"]`）

### FR-2：块渲染

- 元音模式：单词中元音渲染为空放置区，辅音为静态文本
- 音节模式：渲染音节长度的放置区，带位置指示器
- 大师模式：渲染空白组装线（无空位数量提示）

### FR-3：拖拽交互

- 支持指针/触摸从选项池拖到目标位置
- 放置正确：吸附动画 + 音频反馈（宠物吃苹果声）
- 放置错误：弹回动画 + 震动 + 不扣分
- 拖拽项未放入有效位置时返回选项池

### FR-4：连击系统

- 追踪连续完全正确的单词数
- 连续 3 个正确 → "Combo x3!" 火焰特效覆盖
- 连续 5 个正确 → "Combo x5!" 更大火焰特效
- 任何不完整/错误的单词重置连击

### FR-5：完成特效

- 单个单词完成：字母向外炸裂 → 重组 → "Perfect Spelling!" TTS语音
- 连击里程碑：火焰特效 + 连击计数动画
- 本局所有单词完成：局结算画面显示统计

### FR-6：集成接口

- 答错时：向心魔系统（F003）发送事件以创建心魔
- 答对时：向猫头鹰伙伴（F004）发送事件以喂养猫头鹰
- 追踪每个单词的正确率和反应时间，供自适应难度（F003）使用

## 非功能需求

- **性能**：拖拽响应必须 < 16ms（60fps），无丢帧
- **无障碍**：所有拖拽目标至少 44×44px（触屏友好）
- **屏幕**：目标 768×1024（10寸平板），向下兼容至 375px 宽度
- **音频**：音效应预加载，播放无延迟
- **数据**：19 个单词（12个月份 + 7个星期）从本地 JSON 加载，无需网络
