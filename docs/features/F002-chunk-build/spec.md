## 目的

句子构建是比单词拼写更高阶的技能。切块造句将句子按意群/成分切成块而非逐词切分，教学生自然的句子结构。中文提示的递进收窄（块中文→整句中文）将认知负荷从理解（英→中）转向产出（中→英），遵循布鲁姆分类。

## 用户故事

### US-1：单块选择+块中文提示（新手）

**作为** 初学者
**我想要** 在看到缺失块的中文释义时选出正确的块
**以便** 我学会将中文含义匹配到英语短语块

**验收标准：**

- [ ] 句子显示时扣出 1 个块（显示为空位）
- [ ] 扣出块的中文释义显示在空位上方
- [ ] 呈现 4 个选项（1个正确 + 3个干扰项）
- [ ] 点击正确选项 → 块吸附到空位 + 光效
- [ ] 点击错误选项 → 震动 + 不扣分

### US-2：单块选择+整句中文（普通）

**作为** 中级学生
**我想要** 在看到整句中文翻译时选出缺失的块
**以便** 我学会根据上下文推断哪个英语短语对应中文含义

**验收标准：**

- [ ] 句子显示时扣出 1 个块
- [ ] 整句中文翻译显示在句子上方
- [ ] 4 个选项（1正确 + 3干扰项）
- [ ] 选对 → 吸附 + 光效
- [ ] 点击错误选项 → 震动 + 不扣分

### US-3：多块拖回（困难）

**作为** 高级学生
**我想要** 把多个缺失块拖回它们的正确位置
**以便** 我能根据中文语境构建部分句子

**验收标准：**

- [ ] 句子显示时扣出多个块（空位有位置标记）
- [ ] 整句中文翻译显示
- [ ] 选项池包含正确块 + 干扰项
- [ ] 将正确块拖到正确位置 → 吸附 + 光效
- [ ] 拖到错误位置 → 弹回 + 震动
- [ ] 所有块放对 → 飞鸟动画 + 自动播放句子读音

### US-4：全句组装（大师）

**作为** 专家级学生
**我想要** 仅凭中文翻译从碎片组装出完整句子
**以便** 我展示对英语句子构建的完全掌握

**验收标准：**

- [ ] 无句子显示 — 只有空白组装区
- [ ] 中文翻译显示
- [ ] 所有块 + 干扰项在选项池中
- [ ] 玩家自由组合块构建完整句子（不要求从左到右顺序放置，放入错误位置则弹回）
- [ ] 顺序正确+块正确 → 飞鸟 + 语音
- [ ] 任何错误 → 弹回 + 震动

## 功能需求

### FR-1：句子数据模型

每个句子必须包含：
- `sentence`：英文句子（如 "What time do you get up on Monday?"）
- `translation`：中文翻译（如 "你周一几点起床？"）
- `chunks`：有序短语块数组（如 `["What time", "do you", "get up", "on Monday"]`）
- `chunkTranslations`：每个块的中文（如 `["几点", "你", "起床", "在周一"]`）
- `difficulty`：难度浮点值 0-1
- `distractors`：看似合理但不正确的块干扰项池

### FR-2：块空位渲染

- 扣出块的位置显示为带位置指示器的放置区
- 大师模式：空白组装线，无空位提示
- 同一难度等级内，不同句子的空位数量应尽量一致（避免句子长度泄露答案）

### FR-3：拖拽交互

- 支持触摸/指针从选项池拖到目标位置
- 放置正确：吸附 + 咔嗒声 + 相邻块之间亮起连接光效
- 放置错误：弹回 + 震动 + 不扣分
- 困难/大师模式允许部分正确（逐块反馈）

### FR-4：完成特效

- 所有块正确放置：句子化为飞鸟飞走
- 完成后自动播放句子发音（TTS）
- 相邻块正确放置时亮起连接光效

### FR-5：集成接口

- 答错时：向心魔系统（F003）发送事件
- 答对时：向猫头鹰伙伴（F004）发送事件
- 追踪每个句子的正确率和反应时间，供自适应难度使用

---

## 非功能需求

- **性能**：拖拽响应 < 16ms，动画流畅
- **无障碍**：触摸目标 ≥ 44×44px
- **屏幕**：目标 768×1024，向下兼容至 375px
- **音频**：TTS 使用 Web Speech API，音效预加载
- **数据**：约 10 个时间相关句子从本地 JSON 加载，无需网络
