## 目的

虚拟宠物机制通过情感依恋驱动长期参与。猫头鹰伙伴随学生学习进度成长，使知识积累有了具象化呈现。进化链提供里程碑目标，"月份之歌"能力奖励特定知识的掌握。

---

## 用户故事

### US-1：猫头鹰成长

**作为** 学生
**我想要** 每次答对时猫头鹰吃一颗星星并长大
**以便** 我看到与学习绑定的可见进步

**验收标准：**

- [ ] 每次答对触发"吃星星"动画
- [ ] 猫头鹰体型略微增大（单次不可察觉，多次后可见）
- [ ] 星星数量显示在猫头鹰旁边

### US-2：猫头鹰进化

**作为** 学生
**我想要** 猫头鹰在里程碑时刻进化
**以便** 我有令人兴奋的长期目标

**验收标准：**

- [ ] 进化链：蛋（0星）→ 雏鸟（10星）→ 幼年猫头鹰（30星）→ 成年猫头鹰（60星）→ 圣鸟（100星）
- [ ] 进化触发特殊动画（发光、变身、羽毛飞散）
- [ ] 每个进化阶段有独特的视觉外观
- [ ] 进化是单向的（不会退化）

### US-3：月份之歌能力

**作为** 掌握了月份词汇的学生
**我想要** 猫头鹰能大声唱出月份名
**以便** 我感到知识赋予了我的伙伴特殊能力

**验收标准：**

- [ ] 答对 10 道月份题后，猫头鹰解锁"月份之歌"能力
- [ ] 点击猫头鹰播放 TTS 序列："January, February, March..."（Web Speech API）
- [ ] 猫头鹰在"唱歌"时上下摆动/动画
- [ ] 能力指示器显示在猫头鹰资料上

### US-4：游戏中猫头鹰在场

**作为** 学生
**我想要** 猫头鹰在游戏中可见并对答题做出反应
**以便** 我感到陪伴和鼓励

**验收标准：**

- [ ] 猫头鹰栖息在游戏画面角落
- [ ] 答对：猫头鹰高兴地跳一跳
- [ ] 答错：猫头鹰好奇地歪头（永远不表现失望）
- [ ] 连击：猫头鹰兴奋地拍翅膀
- [ ] 进化：猫头鹰飞到画面中央播放变身动画

## 功能需求

### FR-1：猫头鹰数据模型

MVP 必需字段：
- `stars`：总获得星星数
- `evolutionStage`：0-4（蛋、雏鸟、幼年、成年、圣鸟）
- `abilities`：已解锁能力（如 `["month-song"]`）
- `monthCorrectCount`：月份正确答题数，用于能力解锁

扩展预留字段（MVP不实现，post-MVP能力解锁用）：
- `dayCorrectCount`：星期正确答题数
- `sentenceCorrectCount`：句子正确答题数

### FR-2：进化阈值

| 阶段 | 名称 | 所需星星 | 外观 |
|---|---|---|---|
| 0 | 蛋 | 0 | 微光小蛋 |
| 1 | 雏鸟 | 10 | 小巧毛绒雏鸟 |
| 2 | 幼年猫头鹰 | 30 | 小猫头鹰，大眼睛 |
| 3 | 成年猫头鹰 | 60 | 全尺寸猫头鹰，展翅 |
| 4 | 圣鸟 | 100 | 带光晕的华丽鸟 |

### FR-3：能力解锁

- 月份之歌：`monthCorrectCount >= 10` 时解锁
- 未来能力：星期之歌、时间钟鸣（MVP 之后）

### FR-4：动画触发

| 事件 | 猫头鹰反应 |
|---|---|
| 答对 | 跳跃 + 吃星星 |
| 答错 | 歪头（好奇，非失望） |
| 连击 x3 | 拍翅膀 |
| 连击 x5 | 旋转一圈 |
| 进化 | 居中变身动画 |
| 使用能力 | 上下摆动/"唱歌"动画 |

---

## 非功能需求

- **性能**：猫头鹰动画不得影响游戏帧率
- **视觉**：猫头鹰精灵在所有尺寸下清晰可辨（最小 44px）
- **音频**："月份之歌"的 TTS 使用 Web Speech API 英文语音
- **数据**：猫头鹰状态持久化到 IndexedDB
