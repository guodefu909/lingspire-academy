## 目的

传统的错题复习体验是负面且令人沮丧的。心魔系统将错误重新定义为需要征服的敌人，把挫败感变成挑战欲。它将 SM-2 间隔重复算法包装在"心魔生命周期"中，学生感受到的是"打怪"而非"复习"。净化动画是核心情感奖励。

## 用户故事

### US-1：心魔诞生

**作为** 答错的学生
**我想要** 我的错误变成一个"心魔"让我之后去打败
**以便** 我感到被挑战而非被打击

**验收标准：**

- [ ] 任何答错的知识点，若尚无对应心魔，则创建一个心魔
- [ ] 心魔以暗黑外观出现（紫/红发光、阴影效果）
- [ ] 心魔加入次日的每日任务
- [ ] 若该知识点已有心魔，间隔重置为1天

### US-2：心魔削弱

**作为** 拥有活跃心魔的学生
**我想要** 通过答对来削弱心魔
**以便** 我看到向净化迈进的切实进步

**验收标准：**

- [ ] 击败1次（答对）：心魔出现裂痕，间隔移至3天
- [ ] 击败2次：心魔更多裂痕/光线透出，间隔移至7天
- [ ] 击败3次：心魔净化 → 变身动画 → 化为守护精灵
- [ ] 任何阶段再次答错：心魔重新变强，间隔重置为1天

### US-3：心魔净化

**作为** 击败心魔3次的学生
**我想要** 看到心魔被净化并转化为守护精灵
**以便** 我感到坚持带来的深刻情感奖励

**验收标准：**

- [ ] 净化动画：暗黑外壳碎裂 → 光芒绽放 → 正常色彩精灵出现
- [ ] 净化后的精灵加入玩家收集（在精灵图鉴中可见）
- [ ] 净化后的知识点永久移出复习队列
- [ ] 净化触发庆祝特效（粒子、音效）

### US-4：每日任务

**作为** 学生
**我想要** 每日任务包含到期的心魔和新知识题
**以便** 我每天有5-10分钟的结构化学习

**验收标准：**

- [ ] 每日任务包含所有今日到期的心魔
- [ ] 加上 3 道新知识题（未见或最少见的）
- [ ] 任务可在 5-10 分钟内完成
  - [ ] 完成奖励：猫头鹰星星

### US-5：每周任务

**作为** 学生
**我想要** 周末挑战汇总本周的心魔
**以便** 我获得综合复习机会

**验收标准：**

- [ ] 每周任务周末可用
- [ ] 包含过去7天的所有活跃心魔
- [ ] 混合玩法（切块拼写 + 切块造句）
- [ ] 完成有额外奖励

### US-6：每月任务

**作为** 学生
**我想要** 月度大师试炼混合所有知识点
**以便** 我测试综合掌握程度

**验收标准：**

- [ ] 每月任务月末可用
- [ ] 混合所有知识类型（月份、星期、时间）
- [ ] 包含切块拼写和切块造句玩法
- [ ] 完成有重大奖励

## 功能需求

### FR-1：间隔重复算法（SM-2 游戏化）

```
间隔规则：
  答错 → 间隔 = 1天
  答对第1次 → 间隔 = 3天
  答对第2次 → 间隔 = 7天
  答对第3次 → 净化（移出队列）

  任何阶段再次答错 → 重置间隔 = 1天
```

### FR-2：心魔数据模型

每个心魔追踪：
- `knowledgePointId`：关联的单词/句子ID
- `stage`：当前击败阶段（0-3，3为净化）
- `nextReviewDate`：下次出现的ISO日期
- `createdAt`：心魔诞生时间
- `lastDefeatAt`：上次答对时间戳

### FR-3：自适应难度

- 追踪每个知识点的正确率
- 正确率 > 85% → 提升难度等级
- 正确率 < 60% → 降低难度等级
- 正确率 60%-85% → 维持当前等级

### FR-4：任务生成

- 每日：收集所有 `nextReviewDate <= 今天` 的心魔 + 3道新题
- 每周：收集过去7天的所有活跃心魔
- 每月：所有知识点，混合玩法

### FR-5：视觉状态

- 阶段0（新生）：完整暗黑外壳、紫/红发光、凶恶眼睛
- 阶段1（击败1次）：小裂痕、微光渗出
- 阶段2（击败2次）：大裂痕、更多光线可见、姿态减弱
- 阶段3（净化）：碎裂动画 → 正常色彩精灵、柔和光晕

---

## 非功能需求

- **数据**：所有心魔数据存储在 IndexedDB（本地、可离线）
- **性能**：任务生成必须在 < 100ms 内完成
- **动画**：净化动画必须流畅（60fps），持续 2-3 秒
- **离线**：所有任务逻辑无需网络即可工作
