## 任务规则

- **状态**：`[TODO]` → `[DOING]` → `[DONE]`
- **任务沟通/确认**：
  - `[TODO] → [DOING]`：先分享任务标题，再更新任务状态
  - `[DOING] → [DONE]`：先分享结果和验证情况，再更新验收标准和检查清单

  - 在检查清单全部完成前不得标记为 `[DONE]`
- **PRD 映射**：在每条任务行添加 PRD 需求 ID 标签
