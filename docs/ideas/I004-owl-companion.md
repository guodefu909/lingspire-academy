- **创建日期**：2026-07-11
- **状态**：已提升为功能
- **关联功能**：F004-owl-companion
- **PRD 引用**：PRD-FR-023, PRD-FR-024, PRD-FR-025, PRD-US-004

---

## 背景

虚拟宠物机制（如梦幻西游）通过情感依恋驱动长期参与。猫头鹰伙伴随学生学习进度成长，使知识积累有了具象化的呈现。进化链提供里程碑目标，"月份之歌"能力奖励特定知识的掌握。

---

## 大致范围

- 包含：
  - 答对时猫头鹰吃星星长大
  - 进化链：蛋→雏鸟→幼年猫头鹰→成年猫头鹰→圣鸟
  - 进化由正确答题数和连击触发
  - "月份之歌"能力：答对月份题后，猫头鹰通过 Web Speech API 唱出月份名
  - 游戏中可见猫头鹰（栖息在角落，对答题做出反应）

- 不包含：
  - 猫头鹰外观自定义（装扮系统——后续功能）
  - 多种宠物类型（MVP只有猫头鹰）
  - 宠物互动小游戏
  - 宠物命名

---

## 提升备注

- 猫头鹰必须在游戏中可见且对答题有反应——不能只是静态图标
- 进化里程碑应与学习里程碑对齐（而非任意数值）
- "月份之歌"必须真实唱出（TTS），不能只显示文字
- 猫头鹰的情感设计应温暖鼓励，永远不表现出失望
