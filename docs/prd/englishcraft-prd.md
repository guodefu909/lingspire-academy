# EnglishCraft — 产品需求文档

## 1. 项目概述

EnglishCraft 是一款面向中小学生的英语学习网页游戏，将知识内核与游戏机制深度融合，让孩子在游戏过程中自然习得英语词汇与句型。核心原则：**知识本身就是游戏的核心资源**，而非给做题裹一层游戏外衣。

### 世界观：英语魔法学院

孩子是一名魔法学徒，知识 = 魔力，词汇 = 魔法符文。掌握词汇就是掌握魔法力量。心魔是知识的阴暗面，净化心魔就是征服无知。猫头鹰伙伴是魔法的守护者，随学徒的成长而进化。此世界观贯穿UI文案和视觉设计。

## 2. 产品定位

- **产品形态**：网页游戏（PWA），以 10 寸平板为基准屏幕，兼顾 PC
- **目标用户**：中小学生（6-15 岁）
- **使用场景**：课堂辅助练习、课后自主学习、家庭亲子互动
- **单局时长**：5-10 分钟
- **护眼设计**：大字体、高对比度、少用纯白背景、内置休息提醒

## 3. 平台选择

网页优先 + PWA 增强。理由：访问门槛最低（点链接即玩）、屏幕灵活（平板/PC均可）、学校友好（机房/Chromebook直接用）、一套代码多端运行。

## 4. MVP 知识范围

### 4.1 月份（12 个词汇）

January, February, March, April, May, June, July, August, September, October, November, December

### 4.2 星期（7 个词汇）

Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday

### 4.3 时间表达（约 10 个核心句型 + 词汇）

- 整点：three o'clock
- 半点：half past three
- 刻：quarter past / quarter to
- 具体：three fifteen / three forty-five
- 问句：What time is it? / What time do you ___?
- 介词搭配：at + 时间, on + 星期, in + 月份

## 5. 功能需求

### 5.1 切块拼写玩法

- **PRD-FR-001**：系统应将单词按元音位置切开（如 S**e**pt**e**mb**e**r），挖空元音并显示空位标记，供玩家拖拽元音回原位（新手难度）。适用词汇范围：月份（12个）和星期（7个）。

- **PRD-FR-002**：系统应将单词按音节切开（如 Sep|tem|ber），打乱音节块并显示位置标记，供玩家拖拽回原位（普通难度）。适用词汇范围同上。

- **PRD-FR-003**：系统应在音节级切块基础上混入干扰项，供玩家从选项池中选出正确音节块拖拽到标记位置（困难难度）。适用词汇范围同上。

- **PRD-FR-004**：系统应在音节级切块基础上混入干扰项，不显示位置标记，要求玩家自由组合出完整单词（大师难度）。适用词汇范围同上。

- **PRD-FR-005**：系统应在每次正确放入一个块时提供即时视觉和音频反馈（小动画 + 音效）。

- **PRD-FR-006**：系统应在所有块正确放置后播放单词炸裂特效 + "Perfect Spelling!" 语音。

- **PRD-FR-007**：系统应在连续 3 个单词全部正确时显示 "Combo x3!" 火焰特效。

- **PRD-FR-008**：错误放置的块应弹回原位并轻微震动，不扣分。

### 5.2 切块造句玩法

- **PRD-FR-009**：系统应从句子中扣出一个块，显示该块的中文释义，并提供含干扰项的选项供玩家选择正确块（新手难度）。

- **PRD-FR-010**：系统应从句子中扣出一个块，显示整句中文翻译，并提供含干扰项的选项供玩家选择正确块（普通难度）。

- **PRD-FR-011**：系统应从句子中扣出多个块，显示整句中文翻译，玩家需从含干扰项的选项中拖拽正确块回原位（困难难度）。

- **PRD-FR-012**：系统应从句子中扣出全部块，显示整句中文翻译，玩家需从含干扰项的碎片中拖拽组合出完整句子（大师难度）。

- **PRD-FR-013**：系统应在块吸合时播放咔嗒声、正确吸合时亮起连接光效、全句完成时播放飞鸟动画并自动播放句子读音。

- **PRD-FR-014**：错误放置的块应弹回原位并轻微震动，不扣分。

### 5.3 心魔系统（间隔重复）

- **PRD-FR-015**：玩家答错知识点时，系统应为该知识点创建"心魔"并加入次日的每日任务。

- **PRD-FR-016**：心魔生命周期遵循：击败1次（答对）→ 削弱，3天后再现；击败2次 → 进一步削弱，7天后再现；击败3次 → 净化，化为守护精灵。

- **PRD-FR-017**：玩家在心魔知识点上再次答错时，心魔重新变强，间隔重置为1天。

- **PRD-FR-018**：心魔外观为正常精灵的暗黑版（阴影、紫/暗红色、发光眼睛），击败时出现裂痕，净化时暗黑外壳碎裂。

- **PRD-FR-019**：净化动画（暗黑外壳碎裂→光芒绽放→化为正常精灵）是核心驱动力。

### 5.4 任务系统

- **PRD-FR-020**：系统应提供每日任务，包含当日到期的心魔 + 3 道新知识题，5-10 分钟完成。

- **PRD-FR-021**：系统应提供每周任务，汇总本周心魔进行综合挑战。

- **PRD-FR-022**：系统应提供每月任务，混合所有知识点的综合试炼。

### 5.5 猫头鹰伙伴

- **PRD-FR-023**：玩家应有猫头鹰伙伴，每答对一题吃一颗星星并略微长大。

- **PRD-FR-024**：猫头鹰进化链为：蛋→雏鸟→幼年猫头鹰→成年猫头鹰→圣鸟，由累计星星数触发进化（星星通过答对获得）。

- **PRD-FR-025**：玩家答对月份题后，猫头鹰学会"月份之歌"（通过 Web Speech API 真实唱出）。

### 5.6 知识数据

- **PRD-FR-026**：每个单词知识点应包含：英文拼写、音标、中文释义、元音切块模式、音节切块模式、难度值（0-1）、干扰项池。

- **PRD-FR-027**：每个句型知识点应包含：英文句子、中文翻译、短语/成分切块模式、难度值（0-1）、干扰项池。

### 5.7 自适应难度

- **PRD-FR-028**：系统应追踪每个知识点的正确率并自动调整难度：正确率 > 85% → 升级难度；< 60% → 降级难度；60%-85% → 维持。

### 5.8 学习数据追踪

- **PRD-FR-029**：系统应追踪每个知识点的：正确率、上次出现时间、复习次数、当前间隔重复阶段、平均反应时间。

## 6. 用户故事

- **PRD-US-001**：作为学生，我想通过拖拽元音块回到空位来学习单词拼写，从而自然掌握英语元音规律。

- **PRD-US-002**：作为学生，我想将句子切块拼装成完整句子，从而通过动手构建理解英语句型结构。

- **PRD-US-003**：作为学生，我想让答错的知识点变成"心魔"让我去打败，从而被激励去复习而非逃避。

- **PRD-US-004**：作为学生，我想有一只随学习进度成长的猫头鹰伙伴，从而获得陪伴感和成就感。

- **PRD-US-005**：作为学生，我想有每日/每周/每月任务，从而形成有结构的学习习惯而不觉被迫。

- **PRD-US-006**：作为学生，我想游戏难度自动适配我的水平，从而既不无聊也不挫败。

## 7. 非功能需求

- **PRD-NFR-001**：每局游戏时长 5-10 分钟，有自然中断点。

- **PRD-NFR-002**：UI 以 10 寸平板（768×1024）为基准屏幕。

- **PRD-NFR-003**：护眼设计：大字体、高对比度、避免纯白背景、每 10 分钟提醒休息。

- **PRD-NFR-004**：应用为 PWA，支持离线使用和"添加到主屏幕"。

- **PRD-NFR-005**：所有学习数据存储在本地（IndexedDB），MVP 无需服务器。

- **PRD-NFR-006**：绝无付费变强机制。所有外观/奖励仅通过学习获得。

- **PRD-NFR-007**：无虚假体力/能量限制。学生想学多少学多少。

- **PRD-NFR-008**：无嘲讽/羞辱机制。游戏鼓励互助、庆祝进步。

- **PRD-NFR-009**：绝无沉没成本设计。游戏不得利用沉没成本心理（如连续签到断档惩罚、已投入时间不可挽回）绑定用户。

## 8. 技术方案（初步）

| 层面 | 选型 | 理由 |
|---|---|---|
| 游戏引擎 | Phaser 3 | 2D、轻量、生态成熟、Web原生 |
| 前端框架 | 纯 Phaser（不引入 Vue/React） | MVP 界面简单，纯 Phaser 可减少复杂度；UI密集场景用 Phaser DOM Element 补充 |
| 语音 | Web Speech API | 浏览器原生，零成本实现TTS/STT |
| 数据存储 | IndexedDB（Dexie.js） | 离线可用、PWA友好 |
| 部署形态 | PWA | 添加到主屏幕、离线缓存 |
| 基准屏幕 | 10寸平板（768×1024） | 护眼+教育场景主流设备 |

## 9. MVP 范围

### MVP 包含

- 切块拼写玩法 — 月份词汇（12个）+ 星期词汇（7个）
- 切块造句玩法 — 时间句型（约10个）
- 心魔系统（间隔重复）
- 猫头鹰伙伴（基础养成）
- 每日任务、每周任务、每月任务

### MVP 不包含

- 听音辨词玩法
- 时间配对玩法
- 地图探索系统
- 段位系统
- 装扮系统
- 社交功能
- UGC 出题

### MVP 验证目标

- 7日留存率
- 前后测试知识增益
- 心魔系统的间隔重复完成率

## 10. 后续扩展方向

- 更多知识模块：数字、颜色、动物、食物、天气
- 更多玩法：听音辨词、时间配对、朗读评测
- 社交：协作答题、进步排行榜
- UGC：学生/教师出题
- 教师端：班级管理、学情分析
- 多学科：数学、科学、历史
- AI自适应：根据学习数据动态生成题目
